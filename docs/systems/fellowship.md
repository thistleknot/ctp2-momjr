# Fellowship & Morale

## Army Composition Matters

Your army's morale depends on unit **diversity** within a sphere. Mixing different
unit types together produces fellowship bonuses. Mixing across spheres produces
penalties.

## Fellowship Bonus

When 3+ different unit types are co-located (same tile, same owner):

- All units in the stack gain +10% to resistance checks
- This represents unit synergy, mutual support, and combined arms

Requirements:
- At least 3 distinct unit types (not just 3 of the same unit)
- All from the same sphere OR neutral
- Located on the same tile

## Cross-Sphere Penalty

When units from 2+ different spheres are in the same army stack:

- All units suffer -10% to resistance checks
- This represents philosophical conflict, incompatible magic auras

Examples of cross-sphere armies:
- Death Knight + Warbears (Death + Nature) → -10% resist penalty
- Lich + Efreet (Death + Chaos) → -10% resist penalty
- Paladin + Iron Golem (Life + Neutral) → NO penalty (neutral doesn't conflict)

## Neutral Exception

Neutral units (Dwarves, Knights, Settlers, siege) don't trigger the cross-sphere
penalty. They're philosophically compatible with any sphere. You can freely mix:
- Life units + Neutral units → no penalty
- Your sphere's units + Neutral mercenaries → no penalty

Only mixing two non-neutral spheres triggers the penalty.

## The LotR Parallel

This is the Fellowship of the Ring mechanic: a diverse party working together
is stronger than a homogeneous force. But incompatible members (Legolas and Gimli
early on) create friction until they find common ground.

In gameplay terms: build diverse armies within your sphere's roster. Don't mix
spheres unless you have a compelling reason (and accept the resistance cost).

## Interaction with Resistance

The fellowship/morale modifier applies **on top of** the sphere affinity system:

```
1. Determine base resistance tier (0-80%)
2. Add Lamp bonus if applicable (+15%)
3. Add fellowship bonus if diverse same-sphere (+10%)
4. Subtract cross-sphere penalty if mixed (-10%)
5. Roll against final percentage
```

## Strategic Implications

- **Pure sphere armies** with 3+ unit types are the strongest defensively
- **Hero + 2 unit types** counts as 3 types (hero is a type)
- **Neutral mercenaries** can fill out diversity without sphere conflict
- **Cross-sphere mixing** is sometimes worth it for specific unit combos, but
  you pay a defensive cost

## Example: Optimal Life Army

```
Paladin + Unicorn + Guardian Spirit + Ariel (hero)
= 4 distinct Life types
= Fellowship bonus (+10% resist)
= Plus Ariel's hero aura (60% vs Death)
= Plus Paladin's elite opposing (80% vs Death)
= Maximum defensive posture against Death magic
```
